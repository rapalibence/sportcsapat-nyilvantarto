# sportcsapat-nyilvantarto
Szakmai projekt 

Ifjúsági sportcsapat meccs és statisztikai nyilvántartó

Az adatbázis eltárolja a gyerekek adatait(személyes adatok, melyik csapatban játszanak) és a meccsekről a statisztikájukat, ki az edzőjük, az edzéseken a jelenlétüket.
Lesz egy weboldal amin bárki megnézheti ezeknek a meccseknek az statisztikáját, eredményét.
A szülők be tudnak ide jelentkezni és ha kell, tudják szerkeszteni a gyerekek adatait, kapcsolatba léphetnek az edzővel és egymással.
Az edzői felületen az edzők tudják rögzíteni a gyerekek megjelenését az edzéseken és a meccseken. Szintúgy fel tudják vinni a legutóbb játszott meccsek statisztikáját, kik lőttek gólt, labdabirtoklás, ki hány percet volt a pályán, stb.
